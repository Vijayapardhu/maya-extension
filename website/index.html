Usage

How to Use

Two modes. One philosophy: minimal effort, maximum accuracy.

Grand Assessment

Open the test page. The extension silently captures every question from the page's own network data and fills all answers automatically.

No manual input needed

Emp-Skills Deep-Dive

Open a deep-dive test. Each question is answered and the Next Question button advances the flow automatically.

Question after question
Installation

Setup

Five steps. No account. No config files.

1

Unzip the downloaded file to any folder.

2

Open chrome://extensions (or edge://extensions).

3

Enable Developer mode using the top-right toggle.

4

Click Load unpacked and select the unzipped folder.

5

Reload the test page. Answers fill automatically.

Features

What It Does

Built for speed, accuracy, and complete privacy.

Zero Input Required
Load the page and answers fill automatically. No popup, no configuration.
Page-Accurate Answers
Captures questions from the page's own network data. No API drift, no mismatches.
Smart Retry Logic
Waits for data, retries on failure, and self-heals on deep-dive tests.
Privacy First
No external API calls unless you enable Firebase caching or OpenRouter AI.
SPA Navigation
Works with dashboard navigation. No manual refresh needed between tests.
Live Progress Panel
Draggable floating panel shows real-time status, progress ring, and controls.

Troubleshooting

Common Fixes

Quick solutions for the most common issues.

Panel stuck on "Loading..."

On deep-dive, the extension self-heals by fetching matching questions itself. Give it ~10 seconds. If the page shows no question, reload the page.

A question remains unanswered

Click Autofill all. The run re-checks every unanswered question and logs what failed in the console.

CSP inline-script error

You are on the old build. Remove the old extension, load this new version, and reload the test page.

Extension does nothing

Make sure the URL is exactly /grand-assessment/<id> or /emp-skills-deep-dive-in/<id>, you are logged in, and the question card is visible.

Question keeps reloading

The same question failed 3 times. Further reloads are paused to avoid loops. Click Retry to force one more attempt.

Old version persists

Remove all "Maya AutoPilot" entries from chrome://extensions, unzip the new folder, and load it again.
