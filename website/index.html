Installation

Setup

Five steps. No account. No config files.

1

Unzip the downloaded file to any folder.

2

Open chrome://extensions (or edge://extensions).

3

Enable Developer mode using the top-right toggle.

4

Click Load unpacked and select the unzipped folder.

5

Reload the test page. Answers fill automatically.

Bring Your Own API

AI Configuration

The extension works with two AI providers - Google Gemini and OpenRouter. It is fully bring-your-own-key: you paste your own API key, pick a model, and press Connect. No shared key, no sign-up, no key ever leaves your browser.

Google Gemini

Uses the official Google Generative AI endpoint with your personal API key. The default provider - best free-tier speed and the widest model range.

  • Get a key at aistudio.google.com/app/apikey - it starts with AIza
  • Free tier is enough for a full test run
  • Models: Flash, Flash Lite and Pro - newest first
  • Retired models are skipped automatically
OpenRouter

Routes requests through OpenRouter, so one key gives you access to hundreds of models - including the :free ones that cost nothing.

  • Get a key at openrouter.ai/keys - it starts with sk-or-
  • Free :free models need no credits
  • Type any model ID, e.g. openrouter/auto
  • Automatic retry across the free model list

How to connect your key

1
Open the popup

Click the Maya AutoPilot icon in your toolbar. Everything happens in one panel - no config files, no JSON editing.

2
Pick your provider

Press Use Gemini or Use OpenRouter. Gemini is the default - key starts with AIza. OpenRouter - key starts with sk-or-.

3
Paste your key

Drop your key into the password field, then pick a model from the dropdown or type your own model ID.

4
Press Connect

The extension sends a real test request. Only a key that works gets saved - a bad key never overwrites a good one.

Your key is stored only in chrome.storage.local on your own machine. It is sent only to the provider you selected, and it is never bundled into the extension, the download, or the public repo.

Optional

Do I even need an API key?

No. The extension's default path captures every question and answer from the page's own network data and from a shared answer bank, so most tests are already fully answered before any AI is involved. A key only matters when a question is brand new and nobody has answered it yet - the AI is the fallback, not the requirement.

Skip
Skip it entirely

Page capture plus the shared answer bank still fills the test. The AI panel stays greyed out and nothing is sent anywhere.

Recommended
Connect one provider

Adds an AI fallback for questions that are new to the bank, plus a Test AI button so you can confirm the connection yourself.

Both
Switch any time

Keep a Gemini key and an OpenRouter key saved at once, then flip between them with one click. Handy when one hits a quota.

Troubleshooting

Common Fixes

Quick solutions for the most common issues.

Panel stuck on "Loading..."

On deep-dive, the extension self-heals by fetching matching questions itself. Give it ~10 seconds. If the page shows no question, reload the page.

A question remains unanswered

Click Autofill all. The run re-checks every unanswered question and logs what failed in the console.

CSP inline-script error

You are on the old build. Remove the old extension, load this new version, and reload the test page.

Extension does nothing

Make sure the URL is exactly /grand-assessment/<id> or /emp-skills-deep-dive-in/<id>, you are logged in, and the question card is visible.

Question keeps reloading

The same question failed 3 times. Further reloads are paused to avoid loops. Click Retry to force one more attempt.

AI shows "Not connected"

Paste your key, pick a model, then click Connect. The key is only saved when the test request passes - a bad key never overwrites a working one.

AI key rejected (401 / 403)

Check the key in Google AI Studio or OpenRouter Keys. Make sure you selected the correct provider (Gemini vs OpenRouter) in the popup.

Old version persists

Remove all "Maya AutoPilot" entries from chrome://extensions, unzip the new folder, and load it again.
